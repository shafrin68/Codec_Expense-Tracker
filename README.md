# Expense Tracker Application

A data-driven application for managing income and expenses.

## Technologies Used

- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MongoDB
- Programming Language: JavaScript

## Features

- Add income and expenses
- Categorize transactions
- View monthly and yearly summaries
- Calculate total income, expenses and balance
- Edit and delete transactions
- Filter transactions by type
- RESTful CRUD APIs
- MongoDB data storage

## Backend Setup

Install Node.js and MongoDB.

Run:

npm install
npm start

The backend runs on port 5000.

## Frontend Setup

Create a React project using Vite.

Place src.jsx and style.css inside the src folder.

In index.html, change the script path to:

<script type="module" src="/src/src.jsx"></script>

Install dependencies:

npm install react react-dom

Start the frontend:

npm run dev

Ensure MongoDB and the backend server are running.
